سامانه شرکتی — نسخه V42

محتوای بسته:
- index.html: نسخه یک‌تکه آماده جایگزینی در ریشه مخزن GitHub Pages

روش انتشار:
1) از نسخه فعلی index.html یک نسخه پشتیبان بگیرید.
2) فقط index.html داخل ریشه repository را با فایل این بسته جایگزین کنید.
3) Commit کنید و پس از انتشار GitHub Pages، صفحه را با Ctrl+F5 بازخوانی کنید.

بهبودهای V42:
- گردش چندمرحله‌ای شبیه‌سازی‌شده برای درخواست‌های جدید: دورکاری، خرید، پاسخ استعلام، قرارداد مالی، تحصیل و ابطال دارایی و موارد دیگر.
- نهایی نشدن درخواست تا تکمیل آخرین مرحله در گردش دمو؛ رد درخواست هم مسیر را به‌طور شفاف متوقف می‌کند.
- نمایش گام‌های گردش در جزئیات درخواست و ثبت اقدام‌کننده/زمان در سابقه.
- جلوگیری از نمایش کارهای نیازمند اقدامِ بدون تخصیص به کارمند در کارتابل و شمارنده‌های داشبورد.
- جلوگیری از مخفی‌شدن تأیید مجازی وقتی فقط Task قدیمیِ انجام‌شده وجود دارد.
- شناسه یکتای پایدارتر برای درخواست‌ها و ایجاد Task تخصیص‌یافته برای مرحله نخست درخواست‌های جدید.
- همسان‌سازی نوع‌های «خرید» و «ماموریت» با متادیتای SLA و دسته‌بندی.
- حفظ قابلیت‌های قبلی V41 و اصلاحات خوانایی حالت تاریک.

محدودیت مهم:
این نسخه همچنان فرانت‌اند دمو است. گردش چندمرحله‌ای و نقش‌ها در این نسخه شبیه‌سازی می‌شوند؛ کنترل دسترسی واقعی، پایگاه داده، OTP و موتور گردش‌کار امن باید در بک‌اند پیاده‌سازی شوند.
