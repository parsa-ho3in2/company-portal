# سامانه شرکتی — نسخه ۳۰

## تغییرات
- افزودن تم جدید «قرمز شب»: مشکی/زغالی عمیق + قرمز زنده، با استفاده محدود از قرمز برای حفظ خوانایی.
- حفظ کامل قابلیت‌ها و ظاهر نسخه ۲۹.
- بهینه‌سازی رندر افکت پس‌زمینه در موبایل: DPR پایین‌تر و شبکه سبک‌تر برای کاهش مصرف CPU/GPU.
- لودینگ‌ها و اجزای قبلی حذف نشده‌اند.

این نسخه همچنان یک فرانت‌اند دمو است؛ ذخیره‌سازی حساب، OTP و داده‌های محلی برای محیط عملیاتی نیازمند backend امن هستند.
