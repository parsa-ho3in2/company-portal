# سامانه شرکتی — نسخه ۳۲

به‌روزرسانی روی پایه نسخه ۳۱ با تمرکز روی تجربه ورود و موبایل، بدون تغییر در تم و ظاهر اصلی سامانه.

## تغییرات
- بهبود چیدمان و فاصله‌های صفحه ورود در موبایل
- افزایش راحتی لمس فیلدها و دکمه‌ها
- بهینه‌سازی صفحه ورود برای `100dvh` و صفحات کوچک
- حذف blur غیرضروری از پنل ورود موبایل برای کاهش فشار GPU
- افزودن نمایش/مخفی‌کردن رمز عبور
- بهبود خوانایی OTP و ورودی‌های ورود
- بهینه‌سازی کارت ورود با CSS containment
- حفظ لودینگ ورود ۱ ثانیه‌ای، لودینگ بین صفحات ۰٫۲۰ ثانیه‌ای، افکت پس‌زمینه و همه قابلیت‌های نسخه قبلی

این نسخه همچنان یک دمو فرانت‌اند است و ذخیره واقعی حساب/رمز عبور باید توسط مرورگر و Password Manager انجام شود؛ سایت نمی‌تواند Chrome Password Manager را مجبور به نمایش پیشنهاد کند.
