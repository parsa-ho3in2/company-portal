# سامانه سازمانی شرکت - نسخه اول

این نسخه یک MVP فرانت‌اند قابل اجرا در مرورگر است و بدون نصب کتابخانه خارجی اجرا می‌شود.

## اجرا
فایل `index.html` را با مرورگر باز کنید.

## حساب‌های آزمایشی
- کارمند: `employee` / `1234`
- مدیر: `manager` / `1234`
- مدیر سیستم: `admin` / `1234`

## امکانات نسخه اول
- صفحه ورود
- داشبورد
- نقش کارمند و مدیر
- کارتابل
- درخواست‌های من
- تأییدهای مدیر
- فهرست پرسنل
- گزارشات اولیه
- تنظیمات حساب
- طراحی RTL و واکنش‌گرا

## نکته
احراز هویت، دیتابیس، API، ثبت واقعی درخواست‌ها و سطح دسترسی امنیتی در این نسخه پیاده‌سازی نشده و برای مرحله دوم باید بک‌اند و دیتابیس به آن اضافه شود.
