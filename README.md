نسخه ۳۱ — ارتقای کاربردی سامانه

پایه: نسخه ۳۰.

امکانات این نسخه:
- موارد فعال من در داشبورد
- شخصی‌سازی نمایش بخش‌های داشبورد
- مرکز تأیید مدیر با صف‌های واحدی، اولویت و SLA
- فرم‌های هوشمند بر اساس نوع درخواست
- SLA و شمارش‌معکوس مهلت درخواست‌ها
- مرکز دانش سازمانی و بازخورد راهنماها
- میانبر برنامه‌ها / App Launcher
- اعلان‌های سطح‌بندی‌شده (عادی/مهم/فوری)
- جستجوی سراسری گسترده‌تر برای درخواست، کار، اعلان، تیکت و دانش سازمانی
- جزئیات درخواست با SLA و اطلاعات تخصصی فرم

ظاهر، تم‌ها، رعدوبرق و لودینگ‌های نسخه قبل عمداً دست‌نخورده نگه داشته شده‌اند.
این نسخه همچنان دمو و فرانت‌اند است و برای احراز هویت/مجوز/دیتابیس واقعی نیاز به backend دارد.
