نسخه ۲۸ سامانه شرکتی

این نسخه بر پایه V27 است و فقط یک Pass عملکردی برای موبایل اضافه می‌کند، بدون تغییر در ظاهر/تم.

بهینه‌سازی‌ها:
- کاهش DPR بوم افکت روی موبایل
- کاهش چگالی شبکه رعدوبرقی در نمایشگرهای لمسی کوچک
- محدودکردن رندر افکت به حدود ۳۰fps روی موبایل
- حذف allocationهای غیرضروری در حالت بدون حرکت انگشت/موس
- throttle رویداد touchmove
- کاهش کار در زمانی که تب مرورگر مخفی است
- content-visibility برای محتوای خارج از viewport روی موبایل

افکت‌های موجود، لایه زیر رابط و لودینگ‌های قبلی حفظ شده‌اند.
