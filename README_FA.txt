سامانه شرکتی — V44 | سیستم ظاهر و تم‌های پیشرفته

محتوای بسته:
- index.html: نسخه یکپارچه آماده جایگزینی در ریشه مخزن GitHub Pages
- CHANGELOG_FA.md: خلاصه قابلیت‌های V44 و روش استفاده

قابلیت‌های جدید V44:
- حالت نمایش روشن، تیره، نیمه‌تیره (Dim)، مشکی عمیق (AMOLED) و خودکار (System)
- سبک ظاهری مستقل: استاندارد، Glassmorphism، Neumorphism و ترکیبی
- کنتراست بالا با تمرکز واضح‌تر برای دسترس‌پذیری
- ذخیره تنظیمات در همان مرورگر و به‌روزرسانی خودکار حالت System هنگام تغییر تنظیمات سیستم‌عامل
- سازگاری با تم‌های رنگی، فونت و تراکم فعلی؛ جلوه‌های شیشه‌ای در موبایل کم‌حجم‌تر هستند
- سبک استاندارد به‌عنوان پیش‌فرض حفظ می‌شود تا رابط ناخواسته سنگین یا شلوغ نشود

روش نصب:
1) از index.html فعلی مخزن نسخه پشتیبان بگیرید.
2) فقط index.html همین بسته را در ریشه repository جایگزین کنید.
3) Commit کنید و بعد از انتشار GitHub Pages، سایت را با Ctrl+F5 تازه‌سازی کنید.

توجه: این بسته فقط فایل آماده آپلود است و خودکار در GitHub منتشر نشده است. تم‌های جدید در سمت مرورگر کار می‌کنند؛ تأیید انتشار نیازمند Commit/Deploy است. برای Glassmorphism از backdrop-filter استفاده شده و در مرورگرهای ناسازگار، پس‌زمینه به سطح مات برمی‌گردد. در دستگاه‌های کوچک و حالت reduced motion، blur سبک‌تر یا خاموش می‌شود.
